# Tres Tristes Tigres Film Lab 🎞️

Sistema de gestión para laboratorio de fotografía analógica.

## ¿Cómo subirlo a GitHub desde la web?
1. Crea un repositorio nuevo en GitHub (público).
2. Haz clic en **"Upload files"** (Subir archivos).
3. Arrastra los 3 archivos (`app.py`, `database.py`, `requirements.txt`) que extrajiste de este ZIP.
4. Haz clic en **"Commit changes"**.
5. Ve a Streamlit Cloud y despliega tu repositorio.
